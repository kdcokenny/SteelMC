minecraft:block_transformer registry entries.

Vanilla moved this from an inline per-item component to a proper dynamic registry (Registries.BLOCK_TRANSFORMER) referenced by items via Holder<BlockTransformer>. Entries are built from datapack JSON at build time; the item component itself only stores a registry reference.
